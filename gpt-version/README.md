# Website Dr. Anghel Andreea-Diana

Website static de prezentare pentru `angheldiana.ro`, realizat în HTML, CSS și JavaScript simplu.

## Rulare locală în VS Code

### Varianta recomandată: Live Server

1. Deschideți acest folder în VS Code.
2. Instalați extensia **Live Server**, dacă nu este deja instalată.
3. Deschideți `index.html`.
4. Apăsați **Go Live** în bara de jos a VS Code.

Site-ul se va deschide la o adresă locală asemănătoare cu `http://127.0.0.1:5500/`.

### Varianta simplă

Fișierul `index.html` poate fi deschis direct în browser, fără instalarea altor componente. Pentru verificarea completă a navigării este preferată totuși rularea printr-un server local.

## Structura proiectului

- `index.html` — pagina principală
- `despre-mine.html` — parcurs profesional
- `viziunea-mea.html` — viziunea medicală
- `servicii.html` — servicii și consultații
- `unde-ma-gasiti.html` — clinici și programări
- `intrebari-frecvente.html` — întrebări frecvente
- `articole.html` — secțiunea provizorie pentru articole
- `politica-de-confidentialitate.html` — variantă juridică de lucru
- `politica-de-cookie-uri.html` — variantă juridică de lucru
- `informatii-legale.html` — variantă juridică de lucru
- `styles.css` — design și afișare adaptată pentru mobil
- `script.js` — meniul mobil
- `assets/` — imaginile site-ului
- `content/` — textele aprobate și notele editoriale

## Observații pentru persoana care va publica site-ul

- Site-ul nu necesită compilare și nu folosește un framework sau o bază de date.
- Nu conține formular, conturi, newsletter, analiză de trafic sau cookie-uri neesențiale.
- Înainte de publicare trebuie eliminate toate marcajele `[de completat]` din paginile juridice.
- Trebuie confirmate identitatea operatorului, adresa administrativă de e-mail, furnizorul de găzduire și durata jurnalelor tehnice.
- Datele clinicilor și linkurile externe trebuie reverificate înainte de publicare.
- Este necesară configurarea HTTPS, a domeniului, a copiilor de siguranță și a înregistrărilor DNS pentru e-mail, dacă va fi utilizat.
- După instalarea pe server trebuie reverificat dacă sunt introduse cookie-uri sau servicii externe de către platforma de găzduire.
